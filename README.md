# Portofolio Muhammad Raditya Duta Pratama

Website portofolio pribadi milik **Muhammad Raditya Duta Pratama**, siswa SMK TI Dwiguna jurusan Pengembangan Perangkat Lunak dan Gim (PPLG). Website ini dibuat dengan **HTML, CSS, dan JavaScript murni** (tanpa framework) sebagai wadah untuk menampilkan profil, kemampuan, dan proyek-proyek yang sudah dikerjakan.

> Status: dalam pengembangan

---

## Tentang Saya

Siswa aktif SMK TI Dwi Guna jurusan PPLG (Pengembangan Perangkat Lunak dan Gim) yang disiplin dan memiliki motivasi belajar tinggi, serta siap mengikuti program PKL untuk menambah pengalaman di dunia kerja. Memiliki pemahaman dasar pemrograman, pengoperasian komputer, problem solving, dan mampu bekerja sama dalam tim.

## Proyek

### 1. Website Sederhana
Membuat website statis sederhana menggunakan HTML dan CSS.
- Merancang tata letak halaman web agar rapi dan responsif saat diakses
- Mempelajari struktur dasar pemrograman web dan pengelolaan file proyek

### 2. Desain Antarmuka Aplikasi
Mendesain tampilan antarmuka aplikasi menggunakan Figma.
- Merancang alur dan tampilan antarmuka (wireframe/prototype) aplikasi
- Menyusun elemen visual seperti warna, tombol, dan tata letak sesuai arahan tugas sekolah

### 3. Game Flappy Bird 2D
Pembuatan game Flappy Bird 2D menggunakan Scratch.
- Membuat game interaktif dengan memanfaatkan logika blok pemrograman Scratch
- Mengatur alur permainan mulai dari tampilan awal (start), rintangan, hingga game over

## Kemampuan

- **Pemrograman Web:** menguasai dasar HTML, CSS, dan logika pemrograman untuk pembuatan website
- **Design & Layouting:** mampu merancang alur tampilan (wireframe) dan UI menggunakan Figma dan Canva
- **Tools Pemrograman:** terbiasa menggunakan VS Code untuk penulisan kode dan MS Office untuk dokumentasi
- **Soft skill:** adaptif, kemauan belajar tinggi, disiplin, dan mampu bekerja sama dalam tim
